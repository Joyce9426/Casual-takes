# 隨手場記m・場次人員管理 PWA（會員版）

管理每季場次的人員名單、季打、費用與繳費狀況的工具。需要登入帳號才能
使用，不同使用者登入後只看得到自己的資料，admin 帳號則可以看到所有人的
資料。資料存在雲端（Cloudflare D1），本機瀏覽器（IndexedDB）只是加快讀取
速度的快取，登入後會自動跟伺服器同步，不需要手動操作。

## 部署前必做

打開 `js/config.js`，把 `API_BASE_URL` 改成你自己 `relay/` 這個 Worker
部署完成後拿到的網址（部署步驟看 `relay/README.md`）。沒改的話 App 連不上
後端，無法登入、也無法使用任何功能。

這個 App 本身沒有自助註冊功能，帳號要先由 admin 在後端建立（`relay/README.md`
的「步驟六：建立第一個 admin 帳號」），或是已登入的 admin 在 App 內的
「設定 → 使用者管理」建立。

## 功能

- 季度（3 個月一季）與場次管理，建立季度自動產生全季場次
- 場次人員名單（男/女分組），季打管理獨立分頁控制出席/請假（預設出席）
- 季打名單設定，加入時自動帶入季度預收金額，並可批次多選加入
- 冷氣使用紀錄與支出，分攤人數可依場次個別調整
- 繳費方式紀錄（－ 代表未繳）與批量調整（季打與臨打皆可）
- 費用管理與批量調整（臨打）
- 場次／季度統計：應收、已收、支出、應收盈餘、已收盈餘（皆含季打已收金額）、依繳費方式加總
- 季打退款／應補收自動結算，退費顯示「－」、補收顯示紅色「＋」，並可點擊姓名查看/批量調整每場出席紀錄
- 場次名單、季打結算結果可發送到 LINE 聊天室（需另外設定，見「設定」頁的
  「LINE 發送設定」）
- LINE 群組裡可以直接幫別人報名／取消報名（免登入 App），見
  `relay/README.md` 的「代報名／代取消」章節
- 帳號系統：登入才能使用，資料依帳號隔離；admin 可以建立/管理其他使用者
  帳號，並「切換檢視」成任何一個使用者查看/操作他的資料

## 本機測試

因為瀏覽器安全限制，Service Worker（離線快取）與 IndexedDB 在 `file://`
直接開啟時可能無法正常運作，**建議用一個簡單的本機伺服器來開啟**：

```bash
cd app
python3 -m http.server 8080
```

然後用瀏覽器打開 `http://localhost:8080`。因為需要登入才能使用，記得先把
`relay/` 部署好、`js/config.js` 指到正確的網址，並且已經有一組帳號可以
登入。

## 部署到網路上

這是純前端靜態網站（後端是另外部署的 `relay/` Worker），可以直接放到任何
靜態網站託管服務，例如：

- **GitHub Pages**：把這個資料夾內容 push 到一個 repo，開啟 GitHub Pages
  指向該分支即可
- **Cloudflare Pages / Netlify / Vercel**：把資料夾拖拉上傳即可部署，幾
  分鐘內拿到一個網址

部署後用手機瀏覽器打開該網址，可以用「加入主畫面」安裝成 App，登入畫面
會是打開後第一個看到的畫面。

部署好之後，建議回頭把 `relay/wrangler.toml` 裡的 `ALLOWED_ORIGIN` 從
`"*"` 改成這個正式網址，收斂後端只接受這個網站的請求（見
`relay/README.md` 的「安全性小提醒」）。

## 資料備份

資料以伺服器（Cloudflare D1）為主，本機只是快取，正常情況下不會遺失。
「設定」頁的「匯出 JSON 備份」/「匯入 JSON 備份」讀寫的是目前這台裝置的
本機快取（跟登入帳號在伺服器上的資料一致），可以用來做額外備份，或需要
大量調整資料時的手動編修管道。

## 檔案結構

```
index.html              主頁面
manifest.webmanifest    PWA 設定檔
sw.js                   Service Worker（離線快取）
css/styles.css          樣式
js/
  config.js             設定（後端 Worker 網址）
  session.js             登入狀態管理（token、目前使用者、admin 切換檢視）
  api.js                 呼叫後端 Worker 的統一入口
  main.js                入口、路由註冊、開機流程
  router.js               簡易 hash router
  db.js                   IndexedDB 封裝（本機快取）
  sync.js                 雲端同步引擎（自動推送/拉取）
  calc.js                 核心計算邏輯（統計、退款試算）
  utils.js                共用工具函式
  authGate.js             登入畫面
  topbar.js               頂部列（季度切換、同步按鈕、admin 檢視提示列）
  views/                   各頁面（首頁、季度、場次、人員、設定、使用者管理）
liff/daibao.html        LINE 代報名／代取消用的獨立表單頁（不需登入，見
                        relay/README.md 的「代報名（LIFF）設定」）
icons/                  App 圖示
```

## 已知的計算邏輯細節

- 季打「中途加入」試算：固定用「季初預估值」計算，不使用實際場次均價。
- 季打退款：以「(場地費＋冷氣費) ÷ 季打人數快照」的場次人均分攤成本計算，
  請假場次份額視為 0（全額退還）。
